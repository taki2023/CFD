Installation

Stand-alone (Windows)

Unzip the TakiCFD folder anywhere and run TakiCFD.exe. No Python installation is needed. To check an installation, run TakiCFD.exe --selftest: it tests the libraries, the mesher and the solver process and writes a report to ~/.takicfd/selftest.txt.

From source

pip install -r requirements.txt
python main.py                  # or: python main.py path/to/case.json

Required: NumPy, SciPy, Matplotlib, Triangle, PySide6, Pillow. The 3-D workspace adds PyVista, pyvistaqt and gmsh. Optional packages make it faster: pyamg (multigrid pressure solver), numba (multi-core 3-D kernels) and pypardiso (MKL direct solver for the density-based 2-D solvers).

The window

The header shows the six workflow steps. Each step's disc tells its state: a number when it is still to do, a green tick when it is done, an orange mark when it needs attention (hover for the reason). Calculation and Results turn orange when the model changes after the last run.

Below the header, the ribbon holds the tools of the current step; the model tree on the left lists everything in the case; the bottom panel has the messages, the live progress graph and the log. File ▸ Appearance switches between light and dark themes, accent colours and icon styles.

1. Global definitions

  • Dimension: 2-D planar, 2-D axisymmetric or 3-D.
  • Time: steady, or transient with a fixed time step or an automatic one from a CFL number.
  • Solver type: pressure-based (incompressible and weakly compressible) or density-based (compressible, ideal gas).
  • Physics switches: energy equation, gravity, turbulence model, operating pressure.

2. Geometry

The 2-D sketcher draws lines, arcs, circles, splines and rectangles with live snapping. Constraints (coincident, horizontal, vertical, tangent) and smart dimensions keep the sketch parametric; the badge shows the remaining degrees of freedom. Closed loops become surfaces, which are the regions that get a mesh and a material.

Move, mirror and pattern tools show a dashed preview before they are applied. Airfoil profiles can be imported from the bundled library.

3. Mesh

  • Cell type per surface: triangles, quadrilaterals or mixed; neighbouring surfaces share the same nodes on their common curves.
  • Size: maximum element size, maximum aspect ratio and smoothing level; local refinement along chosen curves with a growth ratio.
  • Inflation layers on walls and interior curves, defined by the first-layer height with either the number of layers or the total thickness.
  • Quality: minimum angle, aspect ratio and skewness are reported after every build. Check Conformity and Make Conformal repair interfaces.
  • Overset: a component mesh can overlap a background mesh for moving bodies.

4. Physics

Materials (from the library or user-defined) are assigned to surfaces in 2-D and volumes in 3-D; solids conduct heat. Boundary conditions are assigned to curves (2-D) or surfaces (3-D):

  • Velocity inlet: normal speed or vector, temperature, turbulence intensity and length scale.
  • Pressure outlet: static gauge pressure.
  • Wall: no-slip, free-slip or moving; adiabatic, fixed temperature or heat flux.
  • Symmetry, and the axis in axisymmetric cases.

Anything left unassigned is a no-slip adiabatic wall. Rotating zones use a moving reference frame (steady or transient), a sliding mesh or an overset mesh (transient).

5. Calculation

The Study Setup card has three tabs.

  • Solver: iteration limits, default tolerance, under-relaxation factors and discretisation schemes.
  • Initialization: start values for every cell, and patches that give chosen regions other start values (a hot solid, a jet, fluid at rest).
  • Monitors & Convergence: one tolerance per equation (tick the ones that count for convergence), and monitors of any global or user-defined variable — for example inlet minus outlet mass flow.

A steady run is converged when every ticked residual is below its tolerance and every ticked monitor has settled. A transient run uses the residual table inside every time step and can end by itself once the monitors reach a steady or periodic state.

Pause writes the current solution so it can be inspected in Results and resumed; Stop ends the run and keeps the last completed iteration.

6. Results

Results are organised in figures, each a stack of layers: contours, streamlines, velocity vectors, particle tracks, the mesh, line plots and the convergence history. Colour bars can be edited; transient results have a time bar and export to MP4 or GIF.

Global variables integrate over curves, surfaces or regions (forces, mass flow, mean values, heat flux). User-defined variables combine them with an expression, and both can be monitored during the run.

The 3-D workspace

Switch it on in Global Definitions ▸ Dimension ▸ 3D. The ribbon of each step swaps to its 3-D version.

  • Geometry: sketches on reference planes or model faces; extruded and revolved bosses and cuts with live previews; drag the arrow to set the depth.
  • Mesh: tetrahedra (gmsh) with curvature refinement, local sizes and prism inflation layers grown from chosen surfaces.
  • Results: contours on cut planes, surface contours (pressure, wall shear, y⁺, heat flux), vectors, streamlines, iso-surfaces, volume and surface reports.

A project saves the model in its .json; the mesh and the last results are kept next to it so a reopened case needs no re-meshing.

Numerical methods

Discretisation
Cell-centred finite volumes on unstructured meshes; least-squares gradients; non-orthogonal correction; upwind or limited second-order convection.
Pressure-based
SIMPLE, SIMPLEC, PISO, PIMPLE with Rhie–Chow interpolation; algebraic multigrid for the pressure equation in 3-D.
Density-based
HLLC, Roe, AUSM+-up, HLLE and Rusanov fluxes, MUSCL reconstruction with limiters, explicit or implicit time integration, local time stepping; Weiss–Smith preconditioning for low Mach numbers.
Turbulence
Standard k–ε with wall functions, Wilcox k–ω, Menter k–ω SST, Spalart–Allmaras; wall distance from a Poisson equation.
Heat
Energy equation with conjugate conduction in solids and Boussinesq buoyancy.

Keyboard shortcuts

Ctrl + 1 … 6
Go to a workflow step.
Esc
Cancel the current tool.
Enter
Finish the current sketch entity.
Mouse wheel
Zoom at the cursor; left-drag pans, right-drag zooms a box (2-D views).
